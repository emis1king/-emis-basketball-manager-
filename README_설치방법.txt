EMIS 농구 매니저 — iPad 설치형 웹 앱 패키지

포함 파일
- index.html: V43 게임 본체와 PWA 설정
- manifest.webmanifest: 홈 화면 앱 설정
- service-worker.js: 기본 파일 오프라인 캐시
- icons/: 앱 아이콘

중요: ZIP을 iPad에서 바로 열어서는 홈 화면 앱 설치/오프라인 기능이 완전히 활성화되지 않습니다. iPad Safari의 설치형 웹 앱은 HTTPS 주소로 제공되어야 합니다.

iPad에서 설치하는 방법
1. 이 폴더의 파일 전체를 HTTPS 정적 호스팅에 업로드합니다(예: GitHub Pages). 파일 하나만 올리면 안 됩니다.
2. 배포된 https:// 주소를 iPad Safari에서 엽니다.
3. 공유 버튼 → '홈 화면에 추가'를 선택합니다. 표시되는 경우 '웹 앱으로 열기' 옵션을 켭니다.
4. 홈 화면의 EMIS 아이콘으로 실행합니다.

저장 데이터 안내
- 기존 게임의 저장 방식은 유지됩니다. 브라우저/파일 주소가 달라지면 기존 HTML 파일의 저장 데이터가 자동으로 옮겨지지 않을 수 있습니다.
- 브라우저 데이터 삭제나 사이트 저장 공간 초기화는 저장 데이터를 지울 수 있으니 주의하세요.
- 오프라인 캐시는 최초로 HTTPS 주소에서 게임을 연 뒤 준비됩니다.

이 패키지는 설치형 웹 앱(PWA)이며, Apple App Store용 네이티브 앱 패키지(IPA)는 아닙니다.
